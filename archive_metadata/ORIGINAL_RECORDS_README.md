## 每轮归档规范

用户后续已将当前对话分支限定为只负责Gemini（A）。本分支仅追加A方新材料，不读取或处理B方新结果；表中既有B1是分支前的历史记录，不作为本分支继续同步授权。

- 原输入：实际发出的提示词、上传附件的原文件及顺序（可取得时）、网页截图或导出、显示模型与设置、发送/回复时间。
- 原输出：完整模型回答、可见工具使用与引用；不纠正模型原话。
- 补丁：只去除代码围栏，保留内容，应用结果和原始错误单独保存。
- 执行证据：原始日志、退出码、代码/数据/环境指纹、GPU负载、保留/回退结果及下一轮权威代码。
- 人工介入：记录助手协助提取/归档等操作，以及任何人工修改或偏离；不把归档助手的分析混入模型原答。
